# 大型共享仪器预约与上机资格

资料类型：高校公开制度摘要  
适用范围：大型共享仪器；具体流程以设备所属学校和平台当前规定为准

## 预约前先确认

1. 找到设备管理方指定的预约入口。部分高校或学院使用校级系统、专用 App，也可能保留书面预约；不能假定所有学校使用同一个平台。
2. 核实目标设备是否要求岗前培训、管理员考核或单独授权。重庆大学公开的高使用率仪器办法要求预约人通过相应设备管理员考核并取得操作资格；华南师范大学环境研究院公开办法要求预约前了解设备要求，并完成培训、经管理员确认能熟练使用。
3. 阅读具体设备的使用要求、收费规则和时段限制。若预约规则与设备说明书或现场标识不一致，暂停自助操作并询问管理员。
4. 按所属平台要求完成预约、登记和使用后验收。复旦大学公开的大型仪器通则要求遵守预约、登记和验收制度。

## 时段查询与申请

本项目只检查自己的演示预约记录，并可创建“待审核”预约申请。返回“暂无冲突”只说明演示数据库中暂未登记重叠时段，不表示真实设备空闲，也不代表申请已通过。最终预约结果、培训资格和收费信息应回到学校指定平台确认。

## 助手需要追问的信息

- 设备名称或编号；
- 预约开始和结束时间（含时区）；
- 使用目的；
- 若查询制度而非提交申请，应先说明问题，不会代替用户创建申请。
