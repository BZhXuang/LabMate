# 12 · LabMate 限制与后续工作

代码与真实模型测量日期均为 2026-10-31；10 月 30 日的降级实验另存历史对照。支持某种配置不表示该配置已实际测量或完成生产集成。

| 项目 | 当前状态 | 后续验证 |
|---|---|---|
| 语料 | 30 篇，24 篇自拟演示规则 | 目标学校审核，补可核验原文 |
| 设备/预约/工单 | 本地模拟数据 | 接真实平台前补身份、权限和管理员流程 |
| Embedding | 历史测量中实际加载 BGE small（512 维）；公开副本默认哈希回退 | 下载权重后重新验证，并补更多独立问题、领域适用性与性能测试 |
| Reranker | 历史测量中实际加载 bge-reranker-base；公开副本默认词面回退 | 下载权重后重新验证，并固定候选池做归因、长文本与冷/热性能测试 |
| 评测集 | 意图 120、检索/生成 75、E2E 32 场景 / 51 轮 | 开发回归；补独立审核与真实问题 |
| 自检收益 | RAG/自检均 100% 忠实度、88% 关键词；未触发纠正 | 独立审核与真实纠错失败例 |
| 裁判 | 生成和判断均用 DeepSeek | 独立模型与人工审核 |
| 身份认证 | 请求体 user_id，非可信校园身份 | 服务端验证并绑定真实身份 |
| 待确认动作 | 数据库保存、15 分钟有效，服务重建与独立进程恢复已测 | 多实例首次竞争与历史提案清理 |
| 业务闭环 | 预约 requested；报修登记 | 无真实审批、维修执行或设备控制 |
| 规则提及的流程 | 取消、培训、导出、结算等仅文本 | 未实现对应工具，不能当成已具备功能 |
| 会话记忆 | 恢复 summary，注入有限历史，指代、槽位和摘要回忆已接通 | 更长独立对话、摘要失真与完整提示预算 |
| Token 预算 | 回答后启发式压缩，判级未覆盖全部 prompt | 回答前预算与完整上下文管理 |
| 时区与冲突 | UTC 日界，预约先查后写 | 校园时区、数据库级排他与并发验证 |
| 幂等并发 | 顺序查键复用结果 | 首次竞争与失败恢复，不承诺 exactly-once |
| 能力报告 | dense_backend/reranker 读取实际 provider | LLM 配置和健康不等于输出质量 |
| 知识更新 | 启动 ingest，非完整增量治理 | 删除、版本过滤与索引一致性 |
| 生产运维 | 具备可配置数据库/缓存/向量库 | 未做真实容量、可用性或校园 SLA 验证 |

后端本轮 185 项测试通过，扩库后的规则、检索、DeepSeek 生成与 E2E 已完成；这些不是生产验收。[最新实测](../eval/LABMATE_MEASURED.md) 记录完整数值和限制。扩库前后数据集不同，不能直接宣称指标提升。

历史模型任务曾实际加载 BGE 与 Cross-Encoder，MULTI 分支也有真实模型场景验证；公开副本没有随仓库携带模型权重，默认轻量模式不会加载它们。仍需在当前副本下载权重后重跑独立评测、固定候选池与完整 MULTI 收益消融，再考虑真实校园接入。当前不应继续叠加未验证的模型、工具名或中间件作为简历能力。
