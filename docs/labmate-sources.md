# LabMate 资料来源与核验记录

核验日期：2026-10-30。知识库中的中文内容是为检索整理的摘要和演示规则，不是这些学校或教育部发布的新规。接入实际校园前，应由学校管理员核对适用范围、现行版本和设备型号。

## 项目自拟内容

当前活动目录共 30 篇 Markdown。本次新增的 24 篇 `demo-ops-*.md` / `demo-safety-*.md` 是按用户授权通过 AI 辅助编写的项目原创演示语料，版本为 `LabMate-demo-2026-10-v2`，没有对应高校官方出处，也不新增任何已核验官方文件。每篇注明资料类型，正文段落也保留演示范围，避免切块后误认为真实制度。文件清单见 [知识库目录](labmate-corpus.md)。

新增材料用于流程问答与回归评测，不能当作设备 SOP 或真实应急预案。培训审批、取消改期、计费、样本接收和数据导出等章节仅说明演示业务流程；现有可执行能力仍以 API 工具目录为准。

## 使用方式

- `knowledge/labops/01-laboratory-safety-governance.md` 和 `02-shared-instrument-booking.md` 给出链接和适用范围。
- 重庆大学官方 PDF 的本地核验副本位于 `knowledge/labops/sources/`；该子目录是参考资料，不参与当前知识库扫描，活动检索使用经过整理的 Markdown 摘要。
- `03-instrument-fault-reporting.md` 仅将江苏科技大学学院制度总结为具体案例，不声称其他学校使用相同审批链。
- `04-equipment-operation-boundaries.md` 明确本资料集没有离心机、共聚焦显微镜或灭菌器的具体型号原厂手册。因此不提供转速、温度、压力、装载量、耗材兼容性或故障复位等型号级操作值。
- `05-demo-equipment-catalog.md` 的设备编号、位置、状态、预约和工单是项目模拟数据，不属于上述来源。

本地化部署时，建议由目标学校管理员从本校官网/仪器平台取得当前预约办法、培训要求、应急预案和每台设备对应型号的原厂说明书，再经过审核后替换演示知识库。
